# Impeccable

## Design Context

### Users
Singaporeans (and Singlish-curious friends) killing a few minutes on a typing test.
Mostly desktop with a physical keyboard; a meaningful slice on phones. They arrive
knowing monkeytype — the conventions (tab to restart, blurred idle stream, muted UI)
are inherited on purpose.

### Brand Personality
Kopitiam, not arcade: warm, cheeky, unhurried. Three words: **warm, deadpan, local**.
The Singlish voice lives in the copy ("you asked for it ah", "type until the timer
habis"), never in the mechanics. Lowercase everywhere.

### Aesthetic Direction
Dark espresso room (`#17110d`) with cream text and one kopi-brown accent (`#c8935f`).
Monospace is functional here (per-character alignment for the typing stream), not a
"developer vibe" — keep it, ship JetBrains Mono via next/font so it renders the same
everywhere. Anti-references: neon gamer aesthetics, confetti spam, gradient text,
anything that looks like a crypto dashboard.

### Design Principles
1. **The typing is the star.** Delight amplifies the loop (start → type → result →
   again), never interrupts it. Nothing animates longer than ~600ms.
2. **Cheeky but restrained.** One good line beats three jokes. Celebrations are
   reserved for real moments (new personal best), so they stay special.
3. **Quiet by craft.** Smoothness (caret glide, focus retention, zero layout shift)
   is the main delight channel. Sound is subtle, WebAudio-generated, muteable, and
   remembered.
4. **Never trap the keyboard.** Tab-to-restart only when it can't steal navigation;
   visible :focus-visible everywhere; reduced-motion respected.
5. **No accounts, but memory.** localStorage for personal best and settings —
   "no backend" shouldn't mean amnesia.
